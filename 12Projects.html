Classification of type 2 diabetes by using Machine Learning models-
*Submitted for publication in- Computers in Biology & Medicine- Impact factor-6.3

  • Used a clinical diabetes dataset (1000 samples, 13 features) for multiclass prediction.
  • Built ML models (LR, SVM, KNN, RF, NB, MLP) and a stacking ensemble with GB.
  • Stacking model achieved 98% accuracy, outperforming all individual models.
  • Identified key predictors using SHAP analysis (HbA1c, BMI, Age most influential).
  • Used PDP plots to explain feature interactions and diabetes progression patterns.
